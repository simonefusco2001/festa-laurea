# 🎓 Festa di laurea — Simone Fusco

## 🔗 [Apri l'invito: simonefusco2001.github.io/festa-laurea](https://simonefusco2001.github.io/festa-laurea/)

| 📅 Quando | ⏰ Ora | 📍 Dove | ✅ Rispondi entro |
|---|---|---|---|
| Sabato 31 ottobre 2026 | 19:00 | [Casale Valle Palomba](https://www.casalevallepalomba.it/), Via Nettunense, Anzio (RM) | 23 ottobre |

Invito online alla mia festa di laurea (la seconda, *di nuovo*), costruito come una landing page di marketing con un solo obiettivo di conversione: farti venire alla festa. Tema della serata: Halloween, con gadget obbligatorio.

## Cosa trovi nel sito

| Sezione | Descrizione |
|---|---|
| 🎟️ Biglietto d'ingresso | La prima schermata: un biglietto "Admit one" da strappare per aprire l'invito |
| 🏆 La corsa alla laurea | Minigioco a livelli: l'omino col cappello da laureato salta professori, sessioni, CRM e strategie paid, schiva deadline e corone d'alloro. Classifica del campionato e premio consegnato alla festa |
| 📋 Specifiche tecniche | Data, ora, location, cosa portare e dress code (Birkenstock vietate) |
| 📍 Location | Mappa, foto e link al Casale Valle Palomba |
| 🕖 Programma | Dall'aperitivo delle 19 alla proclamazione del campione, con una sorpresa in mezzo (si suderà) |
| ✅ Conferma la presenza | RSVP con nome e allergie (menù di pesce da chef stellati, forse). Chi prova a dire di no dovrà superare qualche domanda di troppo |
| 🎁 Lista regali, versione onesta | Regali da evitare, idee "per restare umili" e IBAN visibile solo a chi ha confermato |

## Come funziona

| File | Descrizione |
|---|---|
| [`index.html`](index.html) | Biglietto, minigioco, invito e RSVP |
| [`regali.html`](regali.html) | Pagina regali e IBAN |
| [`css/style.css`](css/style.css) | Stile neobrutalism: giallo, corallo, nero e crema, bordi spessi e ombre nette |
| [`js/config.js`](js/config.js) | Tutti i dati dell'evento in un unico file |
| [`js/game.js`](js/game.js) | Il minigioco "La corsa alla laurea" |
| [`apps-script/Code.gs`](apps-script/Code.gs) | Backend su Google Sheet: risposte, punteggi, classifica e IBAN protetto |
| [`img/`](img/) | Sticker, meme e foto della location |
| [`docs/SETUP.md`](docs/SETUP.md) | Istruzioni tecniche per configurare Google Sheet e aggiornare il sito |

HTML, CSS e JavaScript puro, senza framework, ottimizzato per smartphone e pubblicato gratis con GitHub Pages. Le risposte finiscono in un Google Sheet privato del festeggiato.

Foto della location: [casalevallepalomba.it](https://www.casalevallepalomba.it/).
